## Background

Deck Machine already proves the Cursor factory: talk or paste → branded PPTX via rules, skills, and agents. The leave-behind wins demos; weekly use still hits friction — blank-page briefs, export-before-you-see confidence, and a single output type. This deck asks the account team to align on a scoped next increment that grows utility without turning the leave-behind into Office SaaS or diluting the primitives teaching story.

---

## Key messages

The deck should leave the audience with exactly three things:

1. PPTX stays the demo vehicle; Documents and metrics-only Excel are thin renderers on the same brand factory — not a pivot into multi-format automation.
2. MCP into `/create-brief` removes the paste tax by pulling meeting and account context before the interview fills gaps.
3. A revise/preview loop is what makes weekly hire stick — surgical edits and visual confidence before `/export-pptx`.

---

## Content to include

### Data and metrics

- Manual path: days to weeks (design queue + rework)
- Deck Machine path: brief to branded PPTX in minutes (already proven)
- Ring model for scope: brand factory → canonical brief → renderers (PPTX today; Doc + metrics XLSX next)
- Explicit non-goals: animations as a pillar, full Excel financial models, Studio as a multi-format wizard

### Proof points and examples

- Existing pipeline: `/create-brief` → `/build-deck` → narrative-editor + brand-guardian → `output/*.pptx`
- Docs as adjacent job: same voice rules and narrative spine; different exporter
- Excel wedge: export chart/metrics slices from deck JSON into a branded workbook — not a modeling tool
- Teaching constraint: every addition remains “one more skill on the same factory” so Labs still teach Rules / Skills / Agents

### Recommendation or ask

Align on this four-part sequence and defer the rest:

1. Revise/preview loop for decks (confidence before export)
2. MCP into `/create-brief` (Granola / account context when available)
3. `/build-doc` — branded document renderer
4. `/export-metrics-xlsx` — metrics workbook from existing chart/metrics slides

Decide that animations, full workbook modeling, and Studio wizard expansion stay out of scope for this increment.

## What to avoid

- Framing this as a PowerPoint or Office SaaS product
- Positioning as an IT procurement or “AI tool” pitch
- Over-promising full Excel models or animation quality
- Expanding Studio into a multi-format content platform
