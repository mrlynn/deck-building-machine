# Marriott International Brand Voice

## Core principles

**Clear.** Simple language. If a word can be simpler, use the simpler word. Say "use" not "leverage." Say "show" not "demonstrate." Say "start" not "initiate."

**Confident.** State things directly. Remove hedging words: "might," "perhaps," "could potentially," "in some cases." If you're confident in the data, say so directly.

**Warm but professional.** Hospitality DNA. Approachable, not corporate-cold. Write for a person, not a committee.

**Action-oriented.** Lead with what happens. End with what to do. Every slide, every bullet.

---

## Slide writing conventions

### Lead with the conclusion
Do not build to the conclusion — state it, then support it.

❌ "Over the past 90 days, as we rolled out Cursor to engineering teams and gathered usage data, we observed that monthly active users increased significantly, rising from 800 to approximately 1,200..."
✓ "MAU grew 50% in 90 days — from 800 to 1,200 active users."

### Insight headlines, not topic labels
Slide titles must tell you what the slide means, not just what it's about.

| Topic label (wrong) | Insight headline (right) |
|---|---|
| "Cursor Adoption" | "Cursor adoption grew 40% with no formal rollout" |
| "The Problem" | "Deck culture costs the AI Studio ~8 hours a week per person" |
| "Next Steps" | "Three actions to launch the 101 program this week" |
| "Q1 Results" | "Q1 revenue exceeded forecast by 14%" |

## Words to avoid

| Instead of... | Use... |
|---|---|
| Leverage | Use |
| Utilize | Use |
| Synergies | [Describe the actual benefit] |
| Going forward | From here / starting [date] |
| Best-in-class | [Cite the evidence] |
| In this space | [Be specific — which space?] |
| Value-add | [What is the value? State it.] |
| Empower | Help / enable |
| End-to-end | [Describe what is covered] |
| At scale | [How many? At what rate?] |
| Unlock | [What actually happens?] |
| Cutting-edge | [What does it actually do?] |
| Ecosystem | [What are the actual components?] |

---

## Numbers

- Round to the meaningful digit: `1,200` not `1,197`
- Include the context: `1,200 engineers — up from 800 last year`
- Use % for comparisons, absolute numbers for scale
- Cite the source when data is external
- Use specific time windows: `in the last 30 days`, `since January`

---

## Active vs. passive voice

| Passive (wrong) | Active (right) |
|---|---|
| "The program was launched by the team" | "The team launched the program" |
| "Decisions will be made by leadership" | "Leadership decides by July 31" |
| "A 40% increase was observed" | "Usage grew 40%" |

---

## Bullet formatting

- Each bullet is a complete thought, not a label
- Start with a verb where possible: "Grew," "Reduced," "Delivered," "Launched"
- Max ~12 words per bullet — if it needs more, it might be two bullets or a sentence
- No nested bullets
- No bullet that ends with a colon (that's a heading, not a bullet)
